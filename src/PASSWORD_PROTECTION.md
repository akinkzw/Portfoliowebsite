# 🔐 パスワード保護機能

サイト全体をパスワードで保護する機能を実装しています。

## 🎯 機能概要

- ✅ サイト訪問時にパスワード入力を要求
- ✅ ローカルストレージで認証状態を保持
- ✅ 環境変数でパスワードを安全に管理
- ✅ シンプルで使いやすいログイン画面

## 🔧 設定方法

### 開発環境（ローカル）

1. `.env`ファイルを作成（`.env.example`をコピー）
2. パスワードを設定：

```env
VITE_SITE_PASSWORD=your-secure-password
```

3. 設定しない場合、デフォルトパスワードは **`portfolio2024`**

### 本番環境（Vercel）

1. Vercelのプロジェクト設定を開く
2. 「Settings」→「Environment Variables」
3. 以下を追加：

```
Name: VITE_SITE_PASSWORD
Value: your-secure-password
```

4. 保存後、再デプロイ

## 📱 使用方法

### ユーザー視点

1. サイトにアクセス
2. パスワード入力画面が表示される
3. 正しいパスワードを入力してログイン
4. ローカルストレージに認証情報が保存される
5. 次回訪問時は自動的にログイン状態が維持される

### 管理者視点

**パスワードを変更する場合：**
1. Vercelの環境変数を更新
2. ���イトを再デプロイ
3. ユーザーに新しいパスワードを通知

**ログアウトさせる場合：**
- ユーザーにブラウザのローカルストレージをクリアしてもらう
- または、パスワードを変更する

## 🔓 パスワード保護を無効にする

パスワード保護が不要な場合：

`/App.tsx`を編集：

```tsx
// Before（パスワード保護あり）
export default function App() {
  return (
    <PasswordProtection>
      <HashRouter>
        ...
      </HashRouter>
    </PasswordProtection>
  );
}

// After（パスワード保護なし）
export default function App() {
  return (
    <HashRouter>
      ...
    </HashRouter>
  );
}
```

## ⚠️ セキュリティに関する注意事項

### このパスワード保護は：

✅ **適している用途：**
- ポートフォリオの限定公開
- 制作途中のプレビュー共有
- クライアントへの確認用
- 友人・知人への限定公開

❌ **適していない用途：**
- 機密情報の保護
- 個人情報の保護
- 企業の重要データ
- 決済情報など

### 理由

- フロントエンド認証のため、技術的に突破可能
- JavaScriptのコードは誰でも閲覧可能
- パスワードはブラウザに保存される

### より強固な保護が必要な場合

以下のオプションを検討してください：

1. **Vercel Pro** - デプロイメント保護機能（$20/月）
2. **Basic認証** - サーバーサイドで実装
3. **会員制サイト** - データベース + ユーザー認証

## 🔍 トラブルシューティング

### パスワードが機能しない

1. 環境変数が正しく設定されているか確認
2. Vercelで再デプロイを実行
3. ブラウザのキャッシュをクリア

### ログインできない

1. パスワードのスペルミスを確認
2. ローカルストレージをクリア
3. 別のブラウザで試す

### 常にログイン画面が表示される

1. ブラウザがローカルストレージをブロックしていないか確認
2. プライベートブラウジングモードでないか確認
3. Cookieの設定を確認

## 💡 よくある質問

**Q: パスワードは何文字まで設定できますか？**  
A: 制限はありませんが、8文字以上を推奨します。

**Q: 複数のパスワードを設定できますか？**  
A: 現在の実装では1つのみです。複数必要な場合はコードのカスタマイズが必要です。

**Q: パスワードを忘れました**  
A: 環境変数を確認するか、管理者に問い合わせてください。

**Q: ログアウト機能は？**  
A: ブラウザのローカルストレージをクリアすることでログアウトできます。
