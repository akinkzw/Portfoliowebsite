# Creative Portfolio

テキスタイルデザイン、ウェブデザイン、フォトグラフィ、動画制作を中心とした個人ポートフォリオサイト

microCMSと連携し、パスワード保護機能を実装

## 🎨 Features

- レスポンシブデザイン（モバイル・デスクトップ対応）
- React + TypeScript + Tailwind CSS
- React Router による複数ページ対応
- Josefin Sans フォント使用

## 🚀 デプロイ方法

このプロジェクトはVercel、Netlify、Cloudflare Pagesなどの静的サイトホスティングサービスで簡単にデプロイできます。

### Vercelでのデプロイ

1. [Vercel](https://vercel.com)にアクセス
2. GitHubアカウントでログイン
3. このリポジトリをインポート
4. 自動的にビルド・デプロイされます
