# Creative Portfolio

テキスタイル、ウェブデザイン、フォトグラフィーを中心とした個人ポートフォリオサイト

## 🎨 Features

- レスポンシブデザイン（モバイル・デスクトップ対応）
- React + TypeScript + Tailwind CSS
- React Router による複数ページ対応
- Josefin Sans フォント使用

## 🚀 デプロイ方法

このプロジェクトはVercel、Netlify、Cloudflare Pagesなどの静的サイトホスティングサービスで簡単にデプロイできます。

### Vercelでのデプロイ

1. [Vercel](https://vercel.com)にアクセス
2. GitHubアカウントでログイン
3. このリポジトリをインポート
4. 自動的にビルド・デプロイされます
