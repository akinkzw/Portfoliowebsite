# 🔑 Vercel環境変数設定ガイド（詳細版）

## 📍 環境変数とは？

環境変数は、コードに直接書かず、安全に設定値を管理する仕組みです。
APIキーやパスワードなどの機密情報を保護します。

## 🎯 今回設定する環境変数（3つ）

| 変数名 | 説明 | あなたが決める？ |
|--------|------|------------------|
| `VITE_MICROCMS_SERVICE_DOMAIN` | microCMSのサービス名 | ❌ 固定値 |
| `VITE_MICROCMS_API_KEY` | microCMSのAPIキー | ❌ 固定値 |
| `VITE_SITE_PASSWORD` | サイトのログインパスワード | ✅ **自由に決める** |

## 📝 詳細な設定手順

### 手順1: Vercelダッシュボードを開く

1. ブラウザで [vercel.com](https://vercel.com) を開く
2. 右上の「Login」または「Dashboard」をクリック
3. GitHubアカウントでログイン済みならそのまま進む

### 手順2: プロジェクトを選択

Vercelダッシュボードで：
```
┌─────────────────────────────────────┐
│  Overview                           │
├─────────────────────────────────────┤
│  📁 portfolio          [Visit] ▶   │  ← これをクリック
│     https://portfolio-xxx.vercel... │
├─────────────────────────────────────┤
│  📁 other-project     [Visit] ▶    │
└─────────────────────────────────────┘
```

### 手順3: Settings タブを開く

プロジェクトページの上部タブ：
```
┌──────────────────────────────────────────┐
│ [Overview] [Deployments] [Analytics]     │
│ [Logs] [Settings] ← ここをクリック       │
└──────────────────────────────────────────┘
```

#### ③ 3つ目の環境変数を入力（重要！）

**Name欄：**
```
VITE_SITE_PASSWORD
```

**Value欄：**
```
あなたが決めるパスワード
```

⚠️ **ここが重要！**
- 上の2つと違い、この値は**あなたが自由に決めます**
- サイト訪問者がこのパスワードを入力してログインします

**パスワード例：**
- `MyPortfolio2024`（英数字）
- `SecurePass!123`（記号含む）
- `作品確認用パスワード`（日本語OK）
- `Client_Review_2024`（アンダースコア使用）

**推奨：**
- 8文字以上
- 覚えやすいもの
- 他人に推測されにくいもの

**Environment：**
すべてにチェック

**保存：**
「Save」をクリック

### 手順7: 再デプロイを実行（必須！）

環境変数を追加しただけでは反映されません。再デプロイが必要です。

**7-1. Deploymentsタブを開く**

画面上部のタブ：
```
[Overview] [Deployments] ← ここをクリック [Analytics]...
```

**7-2. 最新のデプロイメントを探す**

一番上に表示されているのが最新です：
```
┌──────────────────────────────────────────┐
│ main branch                              │
│ Production                               │
│ https://portfolio-xxx.vercel.app         │
│ Ready • 2 minutes ago            [⋮] ←ここ│
└──────────────────────────────────────────┘
```

**7-3. メニューを開く**

右端の「⋮」（3点メニュー）をクリック

**7-4. Redeployを選択**

メニューから：
```
┌─────────────────┐
│ View Deployment │
│ Redeploy        │ ← これをクリック
│ Promote to Prod │
└─────────────────┘
```

**7-5. 確認ダイアログ**

ポップアップが表示されます：
```
┌────────────────────────────────────┐
│ Redeploy to Production?            │
├────────────────────────────────────┤
│ This will create a new deployment  │
│ using the same source code.        │
│                                    │
│        [Cancel]  [Redeploy]        │
└────────────────────────────────────┘
```

「Redeploy」ボタンをクリック

**7-6. デプロイを待つ**

画面上部にプログレスバーが表示されます：
```

```

通常 2-3分で完了します。

**7-7. 完了確認**

「Ready」と表示されたら完了！
```

```

## 🔄 パスワードを変更したい場合

### 方法1: 環境変数を編集

1. Settings → Environment Variables
2. `VITE_SITE_PASSWORD` の右側の「⋮」メニュー
3. 「Edit」を選択
4. 新しいパスワードを入力
5. 「Save」をクリック
6. **重要**: Deploymentsタブで再デプロイ

### 方法2: 削除して再追加

1. `VITE_SITE_PASSWORD` の右側の「⋮」メニュー
2. 「Remove」を選択
3. 新しく追加（手順5-③）
4. 再デプロイ

## ❌ よくあるエラーと解決法

### エラー1: 「環境変数が反映されない」

**原因**: 再デプロイしていない

**解決**: Deploymentsタブで「Redeploy」を実行

---

### エラー2: 「パスワード画面が表示されない」

**原因**: 環境変数名のスペルミス

**確認**:
- `VITE_SITE_PASSWORD` と正確に入力されているか
- 大文字・小文字が一致しているか
- アンダースコアの位置が正しいか

**解決**: 環境変数を削除して、正確に再入力

---

### エラー3: 「パスワードを入れてもログインできない」

**原因**: 
- パスワードのスペルミス
- 設定した環境変数が反映されていない

**確認**:
1. Settings → Environment Variables で設定値を確認
2. 最新のデプロイメント時刻を確認
3. 環境変数追加後に再デプロイしたか確認

**解決**: 
1. 再デプロイを実行
2. ブラウザのキャッシュをクリア（Ctrl+Shift+R / Cmd+Shift+R）

---

### エラー4: 「ビルドエラーが出る」

**原因**: 環境変数の設定とは無関係の可能性

**確認**: 
- Deploymentsタブでエラーログを確認
- コードに問題がないか確認

**解決**: エラーメッセージを確認して対処

## 💡 Tips

### Tip 1: パスワードを忘れた場合

Settings → Environment Variables で値を確認できます
（ただし、マスクされて表示されます）

→ 新しいパスワードに変更するのが確実

### Tip 2: 複数人で共有する場合

同じパスワードを共有するか、必要に応じて変更

### Tip 3: セキュリティ

- 定期的にパスワードを変更
- 簡単すぎるパスワードは避ける
- 外部に公開しない

### Tip 4: 環境変数の確認方法

ブラウザの開発者ツールでは環境変数は見えません（安全！）
